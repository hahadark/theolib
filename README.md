# 신학 서재

맥 데스크톱 성경·신학 자료 뷰어입니다. Tauri 2 기반이며 화면은 순수 HTML/CSS/JS 로
이루어져 있고 외부 라이브러리나 CDN 없이 동작합니다.

## 설치 파일에는 본문이 없습니다

앱 자체에는 저작권이 있는 성경·주석·사전 본문이 들어 있지 않습니다. 사용자가 자료
출처를 연결해야 자료가 채워집니다. 주소는 운영체제의 보안 저장소에만 보관하고
화면·기록에는 남기지 않습니다.

다만 저작권이 만료되어 누구나 자유롭게 쓸 수 있는 자료(공개 도메인)는 앱에 기본
내장합니다(아래 "기본 내장 자료와 저작권" 절). 주소 없이도 바로 성경을 볼 수 있게
하기 위해서입니다.

## 기본 내장 자료와 저작권

앱에는 저작재산권 보호기간이 끝났거나 자유 이용이 명시된 번역본·사전만 기본 내장합니다.
첫 실행 때(설치된 자료가 없으면) 자동으로 설치되어 주소 없이 바로 성경을 볼 수 있고,
자료 출처 화면에서 [기본 자료 다시 설치] 로 다시 불러올 수도 있습니다.

## 자료를 넣는 세 가지 방법

1. **주소로 받기** — `자료 출처` 탭에서 받은 주소 하나를 붙여 넣습니다. 목록이 나오면
   원하는 항목만 골라 받습니다(중간에 끊겨도 다시 누르면 이어받고, 구간 요청으로 필요한
   부분만 내려받습니다).
2. **파일·폴더로 추가** — `파일로 추가` / `폴더로 추가` 단추로 `.bdb .sdb .dct .cdb`
   같은 자료 파일을 선택합니다. 자료 파일을 창에 끌어다 놓아도 됩니다.
3. **압축 파일 주소** — 압축 파일(또는 릴리스 묶음)의 주소로 받아 그 안의 항목을 골라
   받습니다.

## 화면 기능

- **패널 배치** — 성경 보기 화면을 여러 패널로 나누어 자유롭게 배치합니다. 패널 머리줄을
  끌어 다른 패널 가장자리(왼·오·위·아래)나 가운데에 놓고, 경계선을 끌어 크기를 조절하며,
  배치를 이름 붙여 저장/불러올 수 있습니다.
- **여러 자료 나란히** — 번역본·주석·원전 분해·사전·검색·소논문 패널을 한 화면에 나란히
  두고 같은 구절에 연동해 봅니다.
- **글 서식** — 오른쪽 서랍에서 글꼴·크기·줄 간격·자간·문단 간격·글 폭·정렬·절 번호
  모양·색 테마를 조절합니다. 값이 바뀌면 바로 반영되고, 서식 묶음(프리셋)을 저장할 수도
  있습니다.
- **검색** — 성경 본문과 주석을 검색합니다. 구절 표기를 넣으면 그 자리로 바로 이동합니다.
- **원어 사전** — 본문·주석·원전 분해의 번호를 누르면 원어 사전이 열립니다.
- **주석 글 AI 보정** — 주석 패널의 [보정] 단추로, 스캔한 책에서 옮긴 주석의 줄바꿈·문단·띄어쓰기와
  분명한 글자 오류를 이 PC의 AI로 바로잡습니다. 처음에는 지금 보는 장이 골라져 있고, 장·절
  범위와 풀이를 바꿔 고를 수 있습니다. 보정본은 받은 자료를 고치지 않고 따로 보관하므로(`notefix.db`)
  언제든 원문으로 되돌릴 수 있고, 숫자가 달라졌거나 많이 바뀐 풀이는 원문과 견주어 본 뒤에
  적용합니다. 이 PC에 깔린 구독 명령줄 도구(Codex·클로드 Code)나 저장한 API 키로 동작하며 게스트는 쓸 수 없습니다.
  적용된 보정본은 로그인한 서재에 올라가 다른 사용자의 앱과 웹 성경 보기가 함께 쓰고, 다른 사용자가 올린
  보정본도 주석을 열 때 받아 합칩니다. 한 풀이에 여러 사람이 올렸으면 서재가 하나를 정합니다(관리자 › 특별 계정 ›
  회원, 같은 등급이면 나중 것).

## 빌드

```sh
cargo tauri build --bundles app
```

필요한 도구: Rust(안정판), `cargo`, Tauri 2 CLI(`cargo-tauri`), 그리고 macOS 앱 빌드를
위한 Xcode Command Line Tools.

## 폴더 구조

```
theolib/
├─ ui/                 # 화면 (HTML/CSS/JS): app.js, layout.js, format.js, dev-mock.js 등
├─ crates/
│  ├─ theolib-core/    # 자료·검색·구문해석 등 핵심 로직
│  └─ theolib/         # 그 밖의 라이브러리
├─ src-tauri/          # 데스크톱 앱 껍데기(Tauri 2)
└─ docs/               # 화면 캡처 등
```

## 자료 형식 요약

자료 출처는 선언 파일(`theolib.json`)로 설명합니다. 그 안 `files[]` 의 주요 칸은
다음과 같습니다.

| 칸 | 뜻 |
|-|-|
| `id` | 파일 식별자(예: `bible-ko`, `orig`, `comm`) |
| `kind` | 항목 종류(`bible`/`code`/`lex`/`comm` 등) |
| `name` | 표시 이름 · 번역본/시리즈/사전 id |
| `grp` | 분류(예: 한국어, 영어, 원어) |
| `url` | 내려받을 주소(상대 경로나 자산 이름 가능) |
| `bytes` | 압축 상태 바이트 수 |
| `sha256` | 압축 파일 무결성 값 |
| `db_sha256` | 푼 뒤 통합 DB 무결성 값 |

그 밖에 `db_bytes`(푼 크기), `license`(근거), `contents`(항목 목록) 등을 함께 씁니다.

## AI 본문연구

온라인 신학서재의 AI 본문 연구를 앱에서 그대로 씁니다. 서재 본문은 PC에 내려받지 않고,
온라인 서재의 연결 주소(MCP)와 API 로 찾아 읽습니다. AI 는 앱이 있는 PC에서 돕니다.

- **쓸 수 있는 AI**: 딥시크(API 키), 클로드 구독(이 PC의 Claude Code CLI), 챗GPT 구독(이 PC의 Codex CLI),
  서재 서버의 구독 AI(집 PC), 그 밖의 API 키(제미나이·챗GPT API·클로드 API·직접 넣기).
- **처음 한 번**: `설정 > 계정`에서 서재 계정으로 로그인하고, `설정 > AI 연결`에서 쓸 AI 를 연결합니다. 계정 권한에 따라 쓸 수 있는 AI 와 받을 수 있는 자료가 달라집니다.
  API 키·로그인 정보·연결 주소는 그 컴퓨터의 보안 저장소에만 두며 파일·기록에 남기지 않습니다.
- **화면**: 본문·목적·깊이·요청, 참고할 자료 종류(본문별 건수), 참고 설교 세부 설정과 선호 설교자,
  진행 단계, 보고서, 복사 단추(서식 없이·서식째·설교 개요만·출처 목록·부분 복사), 버튼 질문, 이어서 묻기,
  지난 연구(앱·웹), 출처를 누르면 열리는 서재 읽기 서랍.
- 앱에서 돌린 연구는 그 PC의 자료 폴더(`study/jobs`)에, 서재 서버에서 돌린 연구는 서재 계정에 저장됩니다.
- 화면 디자인 기준: `docs/UI_DESIGN.md`.

명령줄에서 시험할 때:

```sh
theolib study engines
theolib study run --ref "막 2:18-22" --depth quick --engine deepseek
```

## 포터블판

실행 파일 옆에 `data` 폴더(또는 `portable.txt`)가 있으면 그 `data` 를 자료 폴더로 씁니다.
화면 설정(WebView2 자료)도 `data\webview` 에 두어 폴더째 옮길 수 있습니다. 포터블판은 자동 업데이트를 하지 않습니다.
