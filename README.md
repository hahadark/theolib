# 신학 서재

맥 데스크톱 성경·신학 자료 뷰어입니다. Tauri 2 기반이며 화면은 순수 HTML/CSS/JS 로
이루어져 있고 외부 라이브러리나 CDN 없이 동작합니다.

## 설치 파일에는 본문이 없습니다

앱 자체에는 성경·주석·사전 본문이 들어 있지 않습니다. 사용자가 자료 출처를 연결해야
자료가 채워집니다. 주소는 운영체제의 보안 저장소에만 보관하고 화면·기록에는 남기지
않습니다.

## 자료를 넣는 세 가지 방법

1. **주소로 받기** — `자료 출처` 탭에서 받은 주소 하나를 붙여 넣습니다. 목록이 나오면
   원하는 항목만 골라 받습니다(중간에 끊겨도 다시 누르면 이어받고, 구간 요청으로 필요한
   부분만 내려받습니다).
2. **파일·폴더로 추가** — `파일로 추가` / `폴더로 추가` 단추로 `.bdb .sdb .dct .cdb`
   같은 자료 파일을 선택합니다. 자료 파일을 창에 끌어다 놓아도 됩니다.
3. **압축 파일 주소** — 압축 파일(또는 릴리스 묶음)의 주소로 받아 그 안의 항목을 골라
   받습니다.

## 화면 기능

- **패널 배치** — 성경 보기 화면을 여러 패널로 나누어 자유롭게 배치합니다. 패널 머리줄을
  끌어 다른 패널 가장자리(왼·오·위·아래)나 가운데에 놓고, 경계선을 끌어 크기를 조절하며,
  배치를 이름 붙여 저장/불러올 수 있습니다.
- **여러 자료 나란히** — 번역본·주석·원전 분해·사전·검색·소논문 패널을 한 화면에 나란히
  두고 같은 구절에 연동해 봅니다.
- **글 서식** — 오른쪽 서랍에서 글꼴·크기·줄 간격·자간·문단 간격·글 폭·정렬·절 번호
  모양·색 테마를 조절합니다. 값이 바뀌면 바로 반영되고, 서식 묶음(프리셋)을 저장할 수도
  있습니다.
- **검색** — 성경 본문과 주석을 검색합니다. 구절 표기를 넣으면 그 자리로 바로 이동합니다.
- **원어 사전** — 본문·주석·원전 분해의 번호를 누르면 원어 사전이 열립니다.

## 빌드

```sh
cargo tauri build --bundles app
```

필요한 도구: Rust(안정판), `cargo`, Tauri 2 CLI(`cargo-tauri`), 그리고 macOS 앱 빌드를
위한 Xcode Command Line Tools.

## 폴더 구조

```
theolib/
├─ ui/                 # 화면 (HTML/CSS/JS): app.js, layout.js, format.js, dev-mock.js 등
├─ crates/
│  ├─ theolib-core/    # 자료·검색·구문해석 등 핵심 로직
│  └─ theolib/         # 그 밖의 라이브러리
├─ src-tauri/          # 데스크톱 앱 껍데기(Tauri 2)
└─ docs/               # 화면 캡처 등
```

## 자료 형식 요약

자료 출처는 선언 파일(`theolib.json`)로 설명합니다. 그 안 `files[]` 의 주요 칸은
다음과 같습니다.

| 칸 | 뜻 |
|-|-|
| `id` | 파일 식별자(예: `bible-ko`, `orig`, `comm`) |
| `kind` | 항목 종류(`bible`/`code`/`lex`/`comm` 등) |
| `name` | 표시 이름 · 번역본/시리즈/사전 id |
| `grp` | 분류(예: 한국어, 영어, 원어) |
| `url` | 내려받을 주소(상대 경로나 자산 이름 가능) |
| `bytes` | 압축 상태 바이트 수 |
| `sha256` | 압축 파일 무결성 값 |
| `db_sha256` | 푼 뒤 통합 DB 무결성 값 |

그 밖에 `db_bytes`(푼 크기), `license`(근거), `contents`(항목 목록) 등을 함께 씁니다.
