# 신학 서재 화면 디자인 기준

작성: 2026-11-22. 앱 전체 화면을 다듬는 기준이다. 새 화면(AI 본문연구 포함)도 이 기준을 따른다.

## 1. 방향 — "조용한 서재"

지금 화면은 기능은 갖췄지만 테두리 친 작은 단추가 줄지어 있고, 띠(머리줄·도구줄)가 세 겹이라 개발 도구처럼 보인다. 목표는 **책상 위에 펼친 주석서** 같은 화면이다.

원칙 다섯 가지.
1. **본문이 주인공이다.** 성경 본문과 주석 글이 가장 크고 또렷해야 한다. 단추·줄·상자는 필요할 때만 눈에 띈다.
2. **선보다 여백.** 상자와 테두리를 줄이고, 간격과 가는 구분선 하나로 나눈다. 한 화면에 채운(색 있는) 단추는 하나만.
3. **색은 아껴 쓴다.** 종이빛 바탕, 먹빛 글자, 짙은 남색 하나를 주색으로, 옅은 금색은 성경 본문 표시(절 번호·선택한 절)에만.
4. **글자는 두 벌.** 읽는 글(본문·보고서 제목)은 명조, 다루는 글(단추·메뉴·표)은 고딕. 크기 단계는 여섯 개만.
5. **같은 것은 같은 모양.** 단추·입력칸·탭·목록 줄·빈 화면·대화 상자는 앱 어디서나 같은 규칙.

참고한 것: 읽기 화면은 조작부가 가장 시끄러운 요소가 되지 않게 한다는 성경 앱 설계 관행, 한 줄 45~75자·줄 간격 1.5 이상(한글 긴 글은 1.7~1.9)의 가독성 기준, 순검정·순백을 피한 긴 글용 대비(본문 10:1~15:1, 보조 글 5:1~7:1), 형광이 아닌 차분한 강조색.

```
│    │ 도구줄 (화면마다 한 줄, 높이 48px)             │
│ 메 ├──────────────────────────────────────────────┤
│ 뉴 │                                              │
│ 띠 │ 내용                                          │
│76px│                                              │
└────┴──────────────────────────────────────────────┘
```

### 3.1 왼쪽 메뉴 띠 (지금의 위쪽 머리줄을 대신한다)

- 폭 76px, 바탕 `--rail`, 위에서 아래로: 상표(책 안의 십자가 무늬 28px, 그 아래 `신학 서재` 11px 명조) → 메뉴 → (아래 끝) `서식` , `자료`.
- 메뉴 항목: 아이콘 20px + 아래에 이름 11px, 항목 높이 58px, 가운데 정렬. 순서: `성경`, `검색`, `소논문`, `AI 연구`. 아래 묶음: `서식`(지금의 Aa 서식 서랍 열기), `자료`(자료 출처).
- 선택된 항목: 바탕 `--rail-on-bg`, 글자 `--rail-on`, 왼쪽에 3px `--gold` 세로 띠. hover 는 바탕만 옅게. 키보드 초점은 2px 흰 테두리.
- 기존 `<nav id="tabs">` 와 `button[data-view]`·`.on` 구조를 **그대로 쓴다**(위치와 모양만 바뀐다). 머리줄의 `.future`("원본 스캔 · 바구니 · 허브 · AI (준비 중)") 글은 지운다.
- 창 폭 760px 미만이면 메뉴 띠가 아래쪽 가로 띠(높이 54px)로 바뀐다.

### 3.2 도구줄

- 높이 48px, 바탕 `--bg`, 아래 1px `--line`. 왼쪽에 그 화면의 주 조작, 오른쪽에 보조 조작.
- **성경 보기는 지금 두 줄(책·장 줄 + 배치 줄)을 한 줄로 합친다.**
  왼쪽: `[책 ▾] [장 ▾] ‹ ›` · `번역본 (82종 중 1개) ▾` · **구절 이동 칸**(`#goto`, 폭 190px, 돋보기 아이콘, 안내 글 `구절 이동  예: 행 24:10`)
  오른쪽: `＋ 패널`(`#add-panel`) · `배치 ▾`(누르면 작은 메뉴: 배치 저장 `#layout-save` / 배치 불러오기 `#layout-load` / 기본 배치로 `#layout-default`, 메뉴 아래에 지금 배치 이름 `#layout-name`) · `인용 복사`(`#cite`)
  (`Aa 서식` `#format-btn` 은 메뉴 띠의 `서식` 으로 옮긴다. 단추의 id 는 유지해서 기존 코드가 그대로 돌게 한다.)
- 요소의 **id 와 이벤트 연결은 바꾸지 않는다.** 자리와 모양만 바꾼다. 메뉴로 접는 것은 `<details>` 또는 작은 popover 로 감싼다.

## 4. 부품

### 단추
기본 `button` 은 **조용한 단추**: 높이 30px, 좌우 12px, 글자 13px, 바탕 투명, 테두리 1px `--line2`, 둥글기 `--r1`. hover 바탕 `--acc-soft`. 눌림 살짝 어둡게. disabled 는 45% 투명.
- `.btn-primary`: 바탕 `--acc`, 글자 `--on-acc`, 테두리 없음, hover `--acc-h`. **한 영역에 하나만**(예: 연구 시작, 검색, 저장).
- `.btn-quiet`: 테두리 없음(아이콘 단추·도구줄 보조). hover 때만 바탕.
- `.btn-danger`: 글자 `--err`, hover 바탕은 `--err` 10%.
- `.icon-btn`: 28×28, 아이콘 16px, 테두리 없음, `title` 과 `aria-label` 필수.
- 선택 상태(`.on`): 채움이 아니라 바탕 `--acc-soft` + 글자 `--acc` + 굵게. (메뉴 띠만 예외)

### 입력
`input, select, textarea`: 높이 32px(textarea 는 내용대로), 바탕 `--paper`, 테두리 1px `--line2`, 둥글기 `--r1`, 좌우 10px. 초점: 테두리 `--acc` + 바깥 3px `--acc-soft` 링(`box-shadow`), outline 없음. 안내 글(placeholder) `--mut`. 라벨은 칸 위 12px `--fg2` 굵게.
`select` 는 기본 화살표를 지우고 직접 그린 꺾쇠(배경 SVG)를 쓴다.

### 칩(고르는 알약)
높이 28px, 좌우 12px, 둥글기 `--r-pill`, 13px. 꺼짐: 테두리 `--line2`, 글자 `--fg2`. 켜짐: 바탕 `--acc`, 글자 `--on-acc`. 건수는 칩 안 오른쪽에 12px 로 옅게.

### 탭(패널 안, 예: 주석 시리즈·절/장 전체)
밑줄 탭: 글자 13px `--fg2`, 선택되면 `--fg` 굵게 + 아래 2px `--acc`. 상자·알약 모양을 쓰지 않는다. 넘치면 가로 스크롤(스크롤 막대 숨김). 둘 중 하나 고르기(절 / 장 전체)는 작은 분할 단추(바탕 `--bg`, 선택 칸만 `--paper` + 그림자 없음 + 테두리).

### 패널(성경 보기의 칸)
- 바탕 `--paper`. 패널 사이는 1px `--line`(끄는 손잡이 영역은 6px, hover 때 `--acc` 2px).
- 패널 머리: 높이 36px, 왼쪽 제목 13px 굵게 `--fg` + 부제 12px `--mut`, 오른쪽 아이콘 단추들(연동·추가·서식·닫기)은 `.icon-btn` 이고 평소 60% 투명, 패널에 마우스를 올리거나 초점이 들어오면 100%.
- 연동 켜짐 표시는 채운 파란 상자 대신 아이콘 색 `--acc` + 아래 점 하나.

### 성경 본문 줄
- 절 번호: 12px `--gold`, 폭 2.2em 오른쪽 정렬, 본문 첫 줄 기준선에 맞춤.
- 줄 사이 간격은 서식의 문단 간격을 따르되 기본은 넉넉하게. hover: 바탕 `--acc-soft` 40%.
- 선택한 절: 바탕 `--sel` + 왼쪽 3px `--gold` 띠, 둥글기 4px. (지금의 진한 노란 상자를 대신한다)
- 책갈피·메모·하이라이트 표시는 절 번호 옆 작은 아이콘(12px)으로.
- 하이라이트 색: 노랑 `#FBE9A6`, 초록 `#CFE8C9`, 분홍 `#F6CFD0` (어둠에서는 같은 색을 35% 로).

### 주석 글
- 범위 표시(`1:3`, `1:4-5`)는 12px 고정폭 숫자, 글자 `--gold`, 바탕 없음, 뒤에 소제목이 오면 소제목은 14px 굵게.
- 풀이 사이는 `--s5` 여백 + 1px `--line`. 글 폭은 서식 값을 따른다.

### 목록 줄(검색 결과·소논문 목록·지난 연구)
한 줄 높이 최소 44px, 좌우 `--s4`, 아래 1px `--line`, hover `--acc-soft`. 첫 줄 14px `--fg`, 둘째 줄 12px `--mut`. 선택된 줄은 왼쪽 3px `--acc`.

### 카드
바탕 `--paper`, 테두리 1px `--line`, 둥글기 `--r2`, 안쪽 여백 `--s4`~`--s5`. 그림자 없음. 카드 제목 14px 굵게, 제목 아래 설명 13px `--mut`.

### 안내 상자
바탕 `--acc-soft`, 왼쪽 3px `--acc`, 13px. 주의는 `--warn`, 오류는 `--err` 색으로 띠와 글자를 바꾼다(바탕은 그 색 10%).

### 메뉴·서랍·대화 상자
- 메뉴(popover): 바탕 `--paper`, 테두리 `--line`, 둥글기 `--r2`, `--shadow`, 항목 높이 32px, hover `--acc-soft`.
- 서랍(서식·서재 읽기): 오른쪽에서 180ms 로 들어옴, 폭 380px(서재 읽기는 520px), 바탕 `--paper`, 왼쪽 1px `--line` + `--shadow`. 머리에 제목 16px 굵게와 닫기 아이콘.
- 대화 상자: 가운데, 최대 폭 560px, 둥글기 `--r2`, `--shadow`, 뒤는 `rgba(20,24,32,.35)`. 아래 오른쪽에 단추(주 단추가 맨 오른쪽). Esc 로 닫힘.

### 빈 화면
가운데에 아이콘 32px(`--mut`), 한 문장(14px `--fg2`), 필요하면 단추 하나. 예) 검색 처음: "낱말이나 구절을 넣어 찾아보세요" + 예시 칩 3개(`은혜`, `요 3:16`, `하나님의 나라`).

### 진행 표시
막대 높이 4px, 바탕 `--line`, 채움 `--acc`, 둥글기 pill. 글자는 막대 아래 12px `--mut`.

### 아이콘
- 인라인 SVG, 24 viewBox, 선 굵기 1.75, 끝 둥글게, `currentColor`. (Lucide 모양을 따른다. ISC 라이선스이므로 `ui/icons-LICENSE.txt` 에 고지를 둔다.)
- `ui/icons.js` 에 `window.Icon(name)` → SVG 문자열로 모아 둔다: book-open, search, file-text, sparkles, type, database, link, plus, x, chevron-left, chevron-right, chevron-down, copy, bookmark, pencil, layout, settings, check, alert, external, trash, printer, stop, send, log-in, log-out.
- 글자 기호(◀ ▶ ＋ ✕ 🔗 등)로 그리던 단추는 아이콘으로 바꾼다.

### 움직임과 접근성
- hover·눌림 120ms, 서랍 180ms. `prefers-reduced-motion` 이면 전환 없음.
- 모든 조작부에 보이는 초점 표시. 글자 대비는 본문 7:1 이상, 보조 글 4.5:1 이상.
- 스크롤 막대: 가늘게(8px), 평소 `--line2`, hover `--mut`.

## 5. 화면별로 고칠 것

### 성경 보기
3.2 의 한 줄 도구줄, 패널·본문 줄·주석 글 규칙 적용. 번역본 고르는 상자는 메뉴 모양(묶음 제목 12px `--mut`, 체크 줄 높이 30px, 검색 칸 하나)으로.

### 검색
도구줄에 검색 칸(폭 420px)·범위 select·`검색`(`.btn-primary`). 결과는 목록 줄 규칙, 위에 "N건 · 책별 건수 칩". 검색어 강조는 `--hl`(기본 `#FBE9A6`). 빈 화면 규칙 적용.

### 소논문
왼쪽 목록(폭 320px, 목록 줄 규칙, 위에 거르기 칸), 오른쪽 읽는 면(글 폭 44em 가운데, 제목은 명조 20px).

### 자료 출처 (가장 많이 고칠 곳)
가운데 최대 폭 880px, 위에서 아래로 카드 다섯 장.
1. **앱** — 버전, 업데이트 상태·단추(포터블판이면 안내 글만). `업데이트용 GitHub 주소` 는 접힌 채로.
2. **기본 자료** — 저작권 자유 자료 설치 상태, `기본 자료 받기`/`다시 설치`, 저작권 안내는 접힘.
3. **자료 더하기** — 주소 넣기(칸 + `확인`), `파일로 추가` `폴더로 추가`, "파일·폴더를 이 창에 끌어다 놓아도 됩니다" 는 점선 놓는 자리 모양으로.
4. **받은 자료** — 지금의 받은 자료·항목 고르기 상자(모양만 카드·칩 규칙으로).
5. **설치된 출처** — 출처마다 한 줄: 이름, 받은 묶음을 칩으로, 크기, 받은 날짜(`2026-11-21 22:11` 꼴로 다듬어), `갱신 확인` `삭제`(`.btn-danger`).
   **선언 파일의 `note` 를 그대로 보여 주지 않는다**("url 은 이 theolib.json 과 같은 폴더 기준…" 같은 개발자용 글). 날짜는 ISO 문자열을 그대로 내지 않는다.
진행 막대는 카드 아래가 아니라 화면 아래쪽에 붙는 가는 띠로.

### AI 본문연구
양식·진행 단계·보고서·이어서 묻기로 이루어진 화면을 이 문서의 부품으로 그린다.
- 양식은 왼쪽 열(폭 420px, 카드 없이 `--bg` 위에 라벨·칸을 세로로), 결과는 오른쪽 읽는 면(`--paper`). 연구를 열면 결과가 넓게, 이어서 묻기 상자는 결과 오른쪽 열(폭 320px, 창이 좁으면 결과 아래).
- 보고서 글: 제목(h1·h2) 명조 굵게 20/17px, 본문 나눔바른고딕 15.5px·줄 간격 1.85·글 폭 46em, 인용(blockquote)은 왼쪽 3px `--gold` + 바탕 `--acc-soft` 50%, 표는 가는 선·머리줄 `--bg`, 출처 링크는 `--acc` + 점선 밑줄.
- 진행 단계: 시각 12px `--mut` + 문구 13px, 도구 단계는 앞에 작은 점, 마지막 단계는 굵게. 끝나면 "단계 27개" 한 줄로 접힘.
- 버튼 질문(choices): 질문 13px 굵게 + 보기 칩. `next` 는 조용한 단추 줄.
